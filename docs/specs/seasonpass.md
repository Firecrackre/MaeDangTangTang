# 시즌 패스 기획서

## 1. 개요

**시즌 패스**는 플레이어가 게임을 진행하며 미션을 클리어하고, 획득한 점수에 따라 진척도를 올리는 성장형 보상 시스템이다.

현재 메커톤 버전에서는 시간이 부족하므로 시즌 패스의 모든 기능을 완성하지 않고, **확장 가능성을 보여주는 형태**로 구현한다.

실제 구현 범위는 다음으로 제한한다.

* 시즌 패스 창 열기
* 미션 리스트 표시
* 미션 클리어
* 점수 획득
* 진척도 게이지 상승
* 보상 지점 및 치장 아이템 표시

보상 수령, 보상 지급, 시즌 초기화, 유료/무료 패스 구분 등은 현재 버전에서는 구현하지 않는다.

---

## 2. 목표

시즌 패스의 목표는 다음과 같다.

* 플레이어에게 반복 플레이 동기를 제공한다.
* 큐브 사용, 판매, 수익 달성 등 게임 핵심 행동을 미션으로 연결한다.
* 점수와 진척도 게이지를 통해 성장감을 제공한다.
* 향후 치장 아이템, 칭호, 배너 등 보상 시스템으로 확장할 수 있음을 보여준다.
* 현재 버전에서는 실제 보상 지급보다, 시즌 패스 UI와 기본 동작을 보여주는 것을 우선한다.

---

## 3. 진입 방식

시즌 패스는 게임 화면 상단의 **선물상자 아이콘**을 통해 진입한다.

### 진입 흐름

1. 게임 화면 상단에 선물상자 아이콘 표시
2. 플레이어가 선물상자 아이콘 클릭
3. 시즌 패스 창 열림
4. 시즌 패스 진척도와 미션 리스트 표시
5. 창 닫기 버튼 클릭 시 기존 화면으로 복귀

---

## 4. 화면 구성

시즌 패스 창은 크게 왼쪽 영역과 오른쪽 영역으로 구성한다.

* 왼쪽: 시즌 패스 진척도 및 보상 표시
* 오른쪽: 미션 리스트 표시

---

## 5. 왼쪽 영역: 진척도 및 보상

왼쪽 영역에는 시즌 패스의 전체 진행 상황을 표시한다.

### 표시 요소

* 현재 시즌 패스 점수
* 진척도 게이지
* 1000점 지점
* 2000점 지점
* 3000점 지점
* 4000점 지점
* 각 점수 지점 위의 보상 아이콘
* 보상으로 표시되는 치장 아이템

### 진척도 게이지

진척도 게이지는 플레이어가 획득한 시즌 패스 점수에 따라 상승한다.

예를 들어 현재 점수가 1500점이라면, 게이지는 1000점 지점을 지나 2000점 지점으로 향하는 중간 위치까지 채워진다.

### 보상 지점

시즌 패스에는 다음 점수 지점이 존재한다.

|    점수 | 표시 보상  |
| ----: | ------ |
| 1000점 | 치장 아이템 |
| 2000점 | 치장 아이템 |
| 3000점 | 치장 아이템 |
| 4000점 | 치장 아이템 |

현재 버전에서는 보상을 실제로 지급하지 않고, **해당 점수에 도달하면 받을 수 있는 보상처럼 보이도록 표시만 한다.**

---

## 6. 보상 표시 기준

보상은 진척도 게이지 위에 아이콘 형태로 표시한다.

### 보상 표시 방식

* 각 보상은 1000점 / 2000점 / 3000점 / 4000점 지점 위에 배치한다.
* 보상 아이콘에는 치장 아이템 이미지를 사용한다.
* 아직 도달하지 못한 보상은 잠긴 상태처럼 보이게 처리할 수 있다.
* 도달한 보상은 밝게 표시하거나 강조 표시할 수 있다.

### 현재 구현 범위

현재 버전에서는 보상 지급 기능을 구현하지 않는다.

따라서 보상은 다음 용도로만 사용한다.

* 시즌 패스 확장 가능성 전달
* 플레이어의 목표 지점 시각화
* 치장 아이템 보상 구조 예시 제공

---

## 7. 오른쪽 영역: 미션 리스트

오른쪽 영역에는 시즌 패스 미션 리스트를 표시한다.

각 미션에는 미션 내용과 클리어 시 획득할 수 있는 점수가 함께 표시된다.

### 미션 표시 정보

* 미션 이름
* 미션 조건
* 획득 점수
* 클리어 여부
* 클리어 버튼 또는 완료 표시

### 미션 예시

| 미션                       | 획득 점수 |
| ------------------------ | ----: |
| 이상한 큐브 3회 사용             |  300점 |
| 무기 1회 판매                 |  200점 |
| 1회 판매 금액 100,000 메소 달성   |  500점 |
| 총 누적 판매 금액 300,000 메소 달성 |  700점 |
| 장비 파괴 1회 경험              |  300점 |
| 빚 상환 1회 성공               |  400점 |

---

## 8. 미션 클리어 방식

현재 버전에서는 미션 클리어와 점수 획득까지만 구현한다.

### 미션 클리어 흐름

1. 플레이어가 게임을 진행한다.
2. 특정 미션 조건을 만족한다.
3. 해당 미션이 클리어 상태로 변경된다.
4. 미션에 설정된 점수를 획득한다.
5. 시즌 패스 총점이 증가한다.
6. 진척도 게이지가 상승한다.
7. 점수에 따라 보상 지점 도달 상태가 갱신된다.

---

## 9. 점수 획득

미션을 클리어하면 해당 미션에 설정된 점수를 획득한다.

### 점수 처리 기준

* 미션마다 획득 점수가 다르다.
* 미션을 클리어하면 점수가 시즌 패스 총점에 더해진다.
* 이미 클리어한 미션은 중복으로 점수를 지급하지 않는다.
* 점수 획득 후 진척도 게이지를 즉시 갱신한다.

### 예시

* 현재 점수: 800점
* 클리어 미션: 무기 1회 판매
* 획득 점수: 200점
* 변경 후 점수: 1000점
* 결과: 1000점 보상 지점 도달 표시

---

## 10. 진척도 게이지 상승

진척도 게이지는 현재 시즌 패스 점수에 따라 채워진다.

### 게이지 기준

* 최소 점수: 0점
* 최대 표시 점수: 4000점
* 주요 지점: 1000점 / 2000점 / 3000점 / 4000점

### 게이지 처리

* 점수 획득 시 현재 점수 갱신
* 현재 점수에 맞춰 게이지 채움 정도 변경
* 보상 지점 도달 여부 갱신
* 4000점을 초과해도 현재 버전에서는 추가 보상 없음

---

## 11. 보상 도달 표시

현재 버전에서는 보상 지급 기능을 구현하지 않지만, 점수 지점에 도달했는지는 표시한다.

### 도달 전

* 보상 아이콘 어둡게 표시
* 잠금 상태처럼 표시 가능

### 도달 후

* 보상 아이콘 밝게 표시
* 도달 완료 표시 가능
* 게이지가 해당 지점까지 채워짐

### 주의 사항

현재 버전에서는 보상 아이콘을 클릭해도 실제 보상은 지급되지 않는다.

보상은 시즌 패스가 향후 치장 아이템 보상 시스템으로 확장될 수 있음을 보여주는 용도다.

## 17. 확장 가능성

향후 시즌 패스는 다음 기능으로 확장할 수 있다.

* 실제 치장 아이템 지급
* 보상 수령 버튼
* 보상 수령 완료 표시
* 무료 패스 / 프리미엄 패스 구분
* 일일 미션 / 주간 미션
* 시즌 기간 표시
* 시즌 종료 후 보상 정산
* 플레이어 배너 보상
* 칭호 보상
* 대장간 배경화면 보상
* 캐릭터 테두리 보상
* 아바타 치장 보상

현재 버전에서는 위 기능을 실제로 구현하지 않고, 시즌 패스 UI와 진척도 구조를 통해 확장 가능성만 보여준다.

## 18. 정리

시즌 패스는 게임의 반복 플레이 동기를 강화하기 위한 보조 성장 시스템이다.

현재 메커톤 버전에서는 완성형 시즌 패스가 아니라, 다음 요소를 보여주는 데 집중한다.

1. 선물상자 아이콘을 통한 시즌 패스 진입
2. 점수 기반 진척도 게이지
3. 1000점 / 2000점 / 3000점 / 4000점 보상 지점
4. 치장 아이템 보상 표시
5. 미션 클리어
6. 점수 획득
7. 진척도 상승

이를 통해 시즌 패스가 향후 BM 구조, 반복 플레이 동기, 치장 보상 시스템으로 확장될 수 있음을 보여준다.
