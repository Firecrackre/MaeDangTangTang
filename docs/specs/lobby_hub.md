# 로비 허브 기획서

> 로비는 큐브 스크래치·대장 기술 업그레이드·재정 관리 3갈래로 들어가는 **중심 허브**다.
> 각 서브시스템의 세부 규칙은 별도 기획서가 SSOT다.
> - 큐브 스크래치 세부 메커니즘 → `cube_scratch_system.md` (+ `potential_determination.md`)
> - 대장 기술 업그레이드 → `blacksmith_upgrade.md`
> - 재정 관리(대출·저축) → `finance_management.md`
> - 판매가/구매가/상환 수식 → `pricing_calculation.md`
> - 무기 상점(상점 슬롯·무기 등급·구매·갱신) → `weapon_shop.md` (+ `pricing_calculation.md`)

---

## 1. 개요

**로비**는 플레이어가 큐브 스크래치에 진입하기 전, 현재 상황을 확인하고 다음 행동을 선택하는 중심 화면이다.

기존에는 큐브를 사용해 무기의 잠재능력을 확인하고 판매하는 흐름이 핵심이었지만, 추가 시스템 도입에 따라 로비에서 다음 세 가지 기능을 선택할 수 있도록 구성한다.

- 큐브 스크래치
- 대장 기술 업그레이드
- 재정 관리

로비는 단순한 메뉴 화면이 아니라, 플레이어가 현재 메소, 무기 상태, 상환 압박, 업그레이드 효과를 확인하고 다음 행동을 결정하는 전략 선택 공간이다.

---

## 2. 로비의 역할

로비의 역할은 다음과 같다.

- 현재 보유 메소 확인
- 상환 진행도(누적 큐브 사용 n/5) 확인
- 현재 보유 무기 또는 상점 상태 확인
- 큐브 스크래치 진입
- 대장 기술 업그레이드 확인 및 선택
- 재정 관리 기능 이용
- 게임 진행 상황에 따른 위기 대응 선택

플레이어는 로비에서 현재 상황을 확인한 뒤, 큐브를 긁을지, 기술을 강화할지, 재정 관리를 할지 선택한다.

---

## 3. 로비 기능 구성

로비에는 세 가지 주요 기능을 배치한다.

### 1. 큐브 스크래치

큐브를 사용해 무기의 잠재능력을 확인하고, 판매가를 높이는 핵심 플레이 기능이다.
세부 메커니즘은 `cube_scratch_system.md` 참조.

### 2. 대장 기술 업그레이드

게임 진행 중 획득한 강화 효과를 확인하거나 선택하는 기능이다.

리그 오브 레전드 칼바람 아수라장 모드의 증강 시스템, TFT의 증강 시스템처럼 여러 선택지 중 하나를 고르는 방식으로 구성한다. 세부는 `blacksmith_upgrade.md` 참조.

### 3. 재정 관리

메소가 부족한 상황에서 대출을 받거나, 여유 메소를 저축하는 기능이다.

재정 관리는 위기 상황을 한 번 더 버틸 수 있게 하거나, 장기적으로 메소를 불릴 수 있는 보조 시스템이다. 세부는 `finance_management.md` 참조.

## 4. 로비 기본 표시 정보

로비에서는 다음 정보를 표시한다. (단, 보유 메소·상환 필요 메소·상환 진행도는 로비 전용이 아니라 로비/상점/스크래치 **공용 상단 HUD**(`HudGroup`/`HudManager`)로 표시된다.)

- 현재 보유 메소 (공용 상단 HUD, 충분 초록/부족 빨강)
- 현재 날짜 또는 진행 일수 (일차 = DebtStage + 1)
- 상환 진행도 = 누적 큐브 사용 n/5 (0→5, 상환 시점 5/5 — '남은 개수' 감소식이 아니라 진행도 증가식)
- 현재 상환금 (공용 상단 HUD '상환 필요 메소')
- 현재 보유 무기
- 현재 적용 중인 대장 기술 업그레이드
- 큐브 스크래치 진입 버튼
- 대장 기술 업그레이드 버튼
- 재정 관리 버튼

## 5. 로비 기본 흐름

로비의 기본 흐름은 다음과 같다.

1. 게임 시작
2. 로비 진입
3. 현재 메소와 상환 상태 확인
4. 플레이어가 행동 선택
5. 큐브 스크래치 / 대장 기술 업그레이드 / 재정 관리 중 하나 선택
6. 선택한 기능 실행
7. 기능 종료 후 다시 로비로 복귀
8. 다음 행동 선택

로비는 각 시스템으로 들어가는 중심 허브 역할을 한다.

---

## 6. 큐브 스크래치 진입 (요약)

> 큐브 스크래치의 세부 메커니즘(비용 차감·잠재 3줄 생성·순차 공개·판매가 계산·파괴 처리)의 **SSOT는 `cube_scratch_system.md` + `potential_determination.md`**다.
> 여기서는 로비 허브 관점에서의 **진입 조건**과 **복귀 결과**만 정리한다. 중복 기술을 피하기 위해 상세 흐름은 큐브 기획서를 따른다.

### 큐브 스크래치 진입 조건

- 현재 무기를 보유하고 있어야 한다.
- 큐브 사용 비용을 지불할 수 있어야 한다.
- 스크래치 진행 중이 아니어야 한다.
- 게임 오버 상태가 아니어야 한다.

### 로비로의 복귀 결과

큐브 스크래치 종료 후 로비로 돌아올 때 발생하는 상태 변화는 다음과 같다.

- 판매하기 선택 시 메소 획득 후 로비 복귀
- 한 번 더 사용하기 선택 시 같은 무기에 큐브를 다시 사용 (단, 5/5 도달 시 잠김 — 판매만 가능)
- 파괴 발생 시 무기 제거 후 로비 복귀
- 큐브 사용 횟수 조건 도달(5/5) 시 로비 복귀와 함께 **다음주 정산 팝업**이 열려 상환을 처리한다 — 성공 시 다음 주 시작, 5회 성공 시 승리, 실패 시 게임오버 (`finance_management.md` §5-1~§5-2)

## 7. 기능 간 연결 관계

로비 기능은 서로 독립되어 있지만, 게임 진행에서는 서로 연결된다.

### 큐브 스크래치와 대장 기술 업그레이드

- 대장 기술은 큐브 결과에 영향을 줄 수 있다.
- 유효 옵션 등장 확률 증가 기술(대장장이의 눈)은 잠재능력 판정에 영향을 준다.
- 첫 번째 큐브 보장 기술은 큐브 사용 결과에 영향을 준다.

### 큐브 스크래치와 재정 관리

- 큐브 사용에는 메소가 필요하다.
- 메소가 부족하면 큐브를 사용할 수 없다.
- 큐브와 무기를 모두 살 수 없을 때 메소 대출 서비스를 사용할 수 있다.

### 무기 상점과 대장 기술 업그레이드

- 높은 등급 무기 등장 확률 증가 기술(더 좋은 물품 들여오기)은 상점 무기 등급 판정에 영향을 준다.
- 무기 구매가격 감소 기술(가격 협상)은 상점 구매가 계산에 영향을 준다.

### 판매가 계산과 대장 기술 업그레이드

- 위험 거래 기술은 판매가를 증가시킨다.
- 판매가 증가 효과는 최종 판매가 계산에 반영된다.

### 빚 상환과 재정 관리

- 메소 대출 서비스는 현재 상환 필요 메소만큼 지급하고, 같은 금액이 빚으로 누적되어 상환 시 함께 청구된다.
- 위험 거래 기술은 상환 이자를 증가시킬 수 있다.
- 상환금이 증가한 상태에서 메소가 부족하면 게임 오버 위험이 커진다.

## 8. 우선 구현 범위

메커톤 버전에서 우선 구현할 기능은 다음과 같다.

### 필수 구현

- 로비 화면 구성
- 현재 메소 표시 (공용 상단 HUD)
- 상환 진행도(누적 큐브 사용 n/5) 표시 (공용 상단 HUD)
- 큐브 스크래치 진입
- 대장 기술 업그레이드 메뉴
- 대장 기술 선택지 3개 표시
- 대장 기술 1개 선택
- 선택한 대장 기술 효과 적용
- 같은 대장 기술 중복 획득 시 단계 상승
- 메소 대출 서비스
- 대출 시 메소 지급 (현재 상환 필요 메소만큼)
- 대출 시 같은 금액 빚 누적 (상환 시 상환금+빚 일괄 청구)

### 가능하면 구현

- 골드리치 은행 저축
- 저축 메소 관리
- 하루 경과 시 이자 지급
- 저축 메소 출금
